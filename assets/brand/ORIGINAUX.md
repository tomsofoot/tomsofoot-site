# Logos officiels TomsoFoot

Fichiers originaux fournis par Thomas le 21 septembre 2026, créés par sa graphiste.
`logotf4.png` : bleu, pour les fonds clairs. `logotf3.png` : blanc, pour les fonds sombres.
Les fichiers sont conservés octet pour octet. Ne pas les redessiner, recolorier,
déformer, tracer en SVG ou remplacer par une génération IA.
Les PNG/ICO du favicon sont de simples réductions proportionnelles de logotf4.png.
Le fichier favicon.svg est un conteneur du PNG réduit, sans tracé vectoriel recréé.
